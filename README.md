# FinSphere

**Learn. Explore. Analyze. Simulate. Invest.**

FinSphere is a financial-market learning and decision platform for students and beginner investors. It connects education, market exploration, understandable analysis, simulated investing, portfolio tracking, and decision review.

## Product principle

> Don't tell the user what to think. Teach them how to think.

## Initial project direction

The first version is a practical educational web application. Its intended core includes:

- Curated financial learning modules
- A limited catalogue of assets with clear data timestamps
- Plain-language explanations of selected analysis and risk metrics
- Scenario-based investment comparisons with assumptions and trade-offs
- Paper trading with virtual funds
- Portfolio tracking and an investment journal

The first version is for learning and simulation. Real-money trading and brokerage integration are future considerations, not part of the initial build.

## Proposed stack

- Frontend: React or Next.js
- Backend: Python with FastAPI
- Database: PostgreSQL
- Integrations: market-data API and optional AI explanation service
