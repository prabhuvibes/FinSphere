# FinSphere Database

PostgreSQL database schema and migrations for FinSphere.

## Contents
- `schema.sql` - Database schema definition
- `migrations/` - Database migration scripts
- `seeds/` - Sample data for development and testing

## Entities
- Users (accounts, authentication)
- Learning Content (lessons, courses, progress)
- Assets (stocks, ETFs, market data)
- Portfolios (virtual holdings, cash balances)
- Transactions (paper trades, history)
- Journal Entries (investment thesis, reflections)
